# Pocket Keyboard

**Карманная клавиатура для мыши, NumPad и геймпада — by BRADAIGA.**

Дань уважения клавиатурам кнопочных телефонов: 12 кнопок, перебор букв и T9. Знакомый способ набирать текст — теперь на Windows.

## Что умеет

- Ввод текста через 12 кнопок: мышь, цифровой блок, свои назначения и поддерживаемые геймпады.
- Ещё шесть раскладок с перебором букв: украинская, немецкая, французская, испанская, итальянская и португальская.
- Русский и английский: предиктивный T9, ручной перебор букв, обучение новым словам.
- Экранный ввод мышью, удержания и сочетания для повседневных действий.
- Коллекция из 16 тем с поиском, фильтрами, HD-изображениями и живыми сценами.
- Независимый выбор языка интерфейса и раскладки текста.
- Проверка обновлений, скачивание и установка после подтверждения.

## Установка

1. Откройте [последний релиз](https://github.com/BRADAIGA/PocketKeyboard/releases/latest).
2. Скачайте файл **PocketKeyboard-Setup-…exe**. Архивы «Source code», автоматически показанные GitHub, не являются установщиком.
3. Запустите установщик. Ярлык на рабочем столе выбирается по желанию; ярлык в меню «Пуск» создаётся автоматически.
4. В приложении откройте **Настройки → Устройство и клавиши**.

Нужна Windows x64. Установка AutoHotkey отдельно не требуется. Приложение устанавливается для текущего пользователя.

## Первые назначения

Для мыши назначьте боковым кнопкам 1–12 клавиши **F13–F24** в программе производителя. В профиле NumPad расположение повторяет физические кнопки: **7–8–9 / 4–5–6 / 1–2–3 / точка–0–Enter**. Для своих назначений выберите поле и нажмите нужную кнопку устройства.

Кнопка **?** в настройках открывает памятку. Не все игры и защищённые поля принимают программный ввод; поддержка нестандартных HID-устройств зависит от драйвера.

## Обновления и данные

**Настройки → Обновления**: ручная проверка и включение проверки при запуске. При наличии новой версии приложение предложит скачать её, проверит размер и SHA-256 установщика, затем перезапустится после установки.

Настройки и обученные словари установленной версии находятся в `%APPDATA%\PocketKeyboard`. При обновлении они сохраняются. Удаление приложения также сохраняет эти данные. При первом запуске выполняется перенос из последней переносной версии в папке рабочего стола `Клавиатура`, если она есть и данные установленной версии ещё не созданы.

Словари работают офлайн. Проверка обновлений обращается к GitHub; тексты и пользовательские словари туда не отправляются. «Живая сцена» — анимация внутри приложения, а не запись игры.
